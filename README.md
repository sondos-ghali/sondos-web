# 🌐 النشاط الأول: تصميم صفحة ويب بسيطة (HTML & CSS)

> **تسليم النشاط الأول لمساق تطوير وتصميم الويب.**  
> تم بناء الصفحة بالاعتماد على ما تم شرحه في المحاضرات، مع الالتزام بكتابة تعليقات توضيحية لكل جزء والاعتماد فقط على الصورة المرفقة (`landing.jpg`).

---

## 📌 وصف النشاط (Activity Description)
تصميم صفحة هبوط بسيطة ونظيفة لقالب موقع (Leon)، مقسمة إلى أجزاء واضحة وسهلة القراءة، وتعمل بتجاوب مع مختلف أحجام الشاشات باستخدام **HTML5** و **CSS3**.

---

## 📁 ملفات المشروع (Files)
- `index.html`: كود هيكل الصفحة بالكامل مقسم بتعليقات توضيحية لكل قسم.
- `css/style.css`: ملف التنسيقات والألوان وترتيب العناصر.
- `css/normalize.css`: ملف ضبط التنسيقات الافتراضية للمتصفحات.
- `landing.jpg`: الصورة الوحيدة المرفقة بالنشاط، وتم استخدامها كخلفية لقسم اللاندنج.
- `README.md`: هذا الملف التوضيحي للنشاط.

---

## 🧱 أقسام الصفحة (Page Sections)

1. **الهيدر (Header):**
   - يحتوي على اسم الموقع كشعار نصي بسيط (`Leon.`).
   - قائمة تنقل منسدلة وأيقونة القائمة (Hamburger Menu).

2. **قسم اللاندنج (Landing Section):**
   - واجهة ترحيبية تستخدم الصورة المرفقة `landing.jpg` كخلفية.
   - نص ترحيبي في المنتصف (`Hello There`).

3. **قسم المميزات (Features Section):**
   - 3 بطاقات بسيطة توضح خطوات العمل مع أيقونات معبرة من مكتبة Font Awesome.

4. **قسم الخدمات (Services Section):**
   - عرض 4 خدمات يقدمها الموقع (Graphic Design, UI & UX, Web Design, Web Development) بتنسيق شبكي منظم.

5. **قسم من نحن (About Section):**
   - نبذة تعريفية بسيطة عن الفريق وخط فاصل ملون.

6. **قسم التواصل (Contact Section):**
   - بريد إلكتروني نشط وروابط شبكات التواصل الاجتماعي.

7. **الفوتر (Footer):**
   - شريط في نهاية الصفحة يحتوي على حقوق الحفظ.

## 📝 ملاحظات الالتزام بالكود (Code Notes)
- **تنظيم الصفحة:** استخدام وسوم واضحة وبسيطة مثل `<header>`, `<section>`, `<footer>`.
- **التعليقات (Comments):** تم وضع تعليق واضح أعلى كل قسم في ملف `index.html` وفي ملف `style.css` يوضح وظيفته.
- **الصور:** تم استخدام الصورة المرفقة فقط `landing.jpg` ولم يتم إضافة أي صور خارجية ليبقى المشروع مطابقاً للمطلوب وبسيطاً.

## 🚀 طريقة الرفع على GitHub (GitHub Upload Steps)

1. إنشاء مستودع جديد على حسابك في GitHub بالاسم الذي تريده (مثلاً `web-activity-1`).
2. تنفيذ الأوامر التالية من سطر الأوامر (Terminal) في مجلد المشروع:

```bash
git init
git add .
git commit -m "النشاط الأول: تصميم صفحة ويب بسيطة مع التعليقات"
git branch -M main
git remote add origin https://github.com/USERNAME/web-activity-1.git
git push -u origin main
```
*(استبدل `USERNAME` باسم حسابك و `web-activity-1` باسم المستودع).*

3. **تفعيل الرابط المباشر (GitHub Pages):**
   - اذهب إلى **Settings** داخل المستودع.
   - اختر **Pages** من القائمة اليسرى.
   - اختر الفرع `main` ثم اضغط **Save**.
   - سيظهر لك رابط المعاينة المباشر لتسليمه.
