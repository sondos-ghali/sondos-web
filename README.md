## 🌟 نظرة عامة على المشروع (Project Overview)
المشروع عبارة عن صفحة هبوط رئيسية (Landing Page) لوكالة إبداعية تحت اسم **Leon**.  
يتميز التصميم بالبساطة والاحترافية (Minimalist & Modern Design)، ويعتمد على خطوط عصرية وتناسق ألوان هادئ يركز على سهولة القراءة وتجربة المستخدم السلسة.

### ✨ أبرز مميزات الكود:
- **كود دلالي نظيف (Semantic HTML5)**: استخدام وسوم دلالية واضحة (`header`, `nav`, `section`, `article`, `footer`).
- **تنظيم شامل بالتعليقات (Well-Commented Code)**: كل وسم وكل قاعدة تنسيقية مزودة بشرح واضح باللغتين العربية والإنجليزية.
- **تنسيقات موحدة عبر المتغيرات (CSS Custom Properties)**: إدارة الألوان والمسافات عبر `:root` لتسهيل التعديل المستقبلي.
- **تخطيطات حديثة (Modern Layouts)**: الدمج بين **CSS Grid** للبطاقات التلقائية و **Flexbox** للأعمدة والمحاذاة الدقيقة.
- **تجاوب كامل (Fully Responsive)**: يعمل بسلاسة على الهواتف الذكية، الأجهزة اللوحية، وشاشات سطح المكتب.

## 🧩 تفاصيل أقسام الموقع ومكوناته (Website Sections)

### 1. ترويسة الموقع (Header & Navigation)
- يحتوي على الشعار وشريط التنقل.
- زر قائمة الهامبرغر المبتكر (Hamburger Menu) المصنوع بـ **CSS الخالص** دون الحاجة إلى مكتبات خارجية.
- قائمة منسدلة متحركة (Dropdown Menu) تظهر بسلاسة عند التمرير بالماوس مع سهم إشارة علوي عبر `::before`.
- روابط انتقال سلس (Smooth Scrolling) تأخذ الزائر مباشرة إلى القسم المطلوب.

### 2. واجهة الترحيب (Landing Section)
- تشغل الشاشة الرئيسية بالكامل (`height: calc(100vh - 64px)`).
- استخدام صورة جبال خلابة مع ميزة `background-size: cover` لضمان تغطية كاملة.
- نص ترحيبي عريض متموضع بدقة رياضية في مركز الشاشة عبر:
  ```css
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
  ```

### 3. قسم المميزات (Features Section)
- عرض 3 بطاقات لمراحل العمل الأساسية (الفكرة، التنفيذ، والوصول العالمي).
- مبني بواسطة **CSS Grid** عبر الأمر الفعال:
  ```css
  grid-template-columns: repeat(auto-fill, minmax(300px, 1fr));
  ```
  مما يسمح للبطاقات بإعادة ترتيب نفسها تلقائياً حسب عرض الشاشة دون الحاجة لكتابة استعلامات وسائط إضافية.

### 4. المكون العام للعناوين (Special Heading Component)
- أسلوب تصميم حديث يجمع بين عنوان مائي خلفي ضخم (`font-size: 100px; color: #ebeced`) متبوعاً بنص توضيحي أصغر متداخل معه بسلاسة عبر هامش سلبي (`margin-top: -30px`).

### 5. قسم الخدمات (Services Section)
- مقسم إلى 3 أعمدة:
  - عمودان يحتوي كل منهما على خدمتين مميزتين (تصميم جرافيك، واجهات مستخدم، تصميم وتطوير ويب) مع أيقونات معبرة ومحاذاة مرنة بـ **Flexbox**.
  - عمود ثالث مخصص لصورة جمالية مع خلفية لونية هندسية مبتكرة تضفي طابعاً ثلاثي الأبعاد.

### 6. معرض الأعمال (Portfolio Section)
- شبكة متجاوبة من بطاقات المشاريع مع صور مميزة ونصوص تعريفية.
- تأثير تفاعلي خفيف وظل أنيق عند تحريك الفأرة فوق البطاقة (`transform: translateY(-5px)`).

### 7. قسم من نحن (About Section)
- نبذة تعريفية عن فلسفة ورؤية الوكالة.
- استخدام إطار فني خلف الصورة بواسطة العناصر الزائفة (`::before` و `::after`).
- خط فاصل أنيق ملون باللون الرئيسي يفصل بين الفقرات.

### 8. قسم التواصل (Contact Section)
- دعوة مباشرة للعمل (Call to Action) تشجع العميل على التواصل.
- بريد إلكتروني نشط بصيغة `mailto:` بخط عريض ملفت للنظر.
- أيقونات الشبكات الاجتماعية مع تأثيرات لونية عند التحويم.

### 9. تذييل الصفحة (Footer)
- شريط سفلي باللون الكحلي الداكن المعتمد يحمل حقوق الملكية مع إبراز اسم الوكالة باللون التركوازي الرئيسي.

## 📱 التصميم المتجاوب ونقاط الكسر (Responsive Design)

تم ضبط هوامش وحاويات الصفحة (`.container`) للعمل بدقة متناهية وفق النقاط المعيارية:
- **الشاشات الصغيرة جداً (< 768px)**: عرض الحاوية 100% مع هوامش جانبية 15px وتكديس العناصر عمودياً.
- **الشاشات المتوسطة (≥ 768px)**: عرض الحاوية الثابت 750px.
- **شاشات الحواسيب (≥ 992px)**: عرض الحاوية 970px.
- **الشاشات الكبيرة (≥ 1200px)**: عرض الحاوية 1170px.

## 💻 طريقة تشغيل المشروع محلياً (How to Run Locally)

1. **الفتح المباشر:**
   - يمكنك فتح ملف `index.html` مباشرة بالنقر المزدوج عليه في أي متصفح (مثل Chrome أو Edge أو Firefox).

2. **باستخدام إضافة Live Server (موصى به في VS Code):**
   - افتح المجلد داخل محرر Visual Studio Code.
   - انقر بزر الفأرة الأيمن على ملف `index.html` واختر **Open with Live Server**.

## 🚀 خطوات الرفع على GitHub وتفعيل الاستضافة المجانية (GitHub Deployment)

لرفع هذا المشروع والحصول على رابط التسليم المباشر:

### 1. تهيئة المستودع محلياً وتأكيد الملفات:
```bash
git init
git add .
git commit -m "Initial commit: Complete Leon Template with clean code & comments"
```

### 2. ربط المشروع بمستودع GitHub:
1. توجه إلى موقع [GitHub](https://github.com) وقم بتسجيل الدخول.
2. أنشئ مستودعاً جديداً (New Repository) وسمّه مثلاً: `leon-template`.
3. انسخ الأوامر الظاهرة في صفحة المستودع ونفذها في الطرفية (Terminal):
```bash
git branch -M main
git remote add origin https://github.com/USERNAME/leon-template.git
git push -u origin main
```
*(استبدل `USERNAME` باسم حسابك على GitHub)*.

### 3. تفعيل استضافة GitHub Pages المجانية لمعاينة الموقع حياً:
1. داخل صفحة المستودع على GitHub، اذهب إلى تبويب **Settings**.
2. من القائمة الجانبية اختر **Pages**.
3. تحت قسم **Build and deployment**:
   - اضبط **Source** على `Deploy from a branch`.
   - اختر الفرع `main` والمجلد `/ (root)`.
   - اضغط **Save**.
4. خلال دقيقة سيظهر لك رابط الموقع المباشر بصيغة:
   `https://USERNAME.github.io/leon-template/`
